# مستندات فارسی

[English](../README.md) · **فارسی**

همهٔ مستندات کرم‌چاله به فارسی هم هست. نام تنظیم‌ها، دستورها و مقدارها به انگلیسی می‌ماند، چون همان‌ها را در کانفیگ و ترمینال می‌نویسید. این صفحه‌ها نسخهٔ ۱٫۰٫۰ را شرح می‌دهند؛ تغییرهای هر نسخه در [تغییرات](CHANGELOG.md) آمده است. همین صفحه‌ها با جستجو، نمودارهای متحرک و دموی زندهٔ پنل در وب‌سایت هستند: <https://byecoder.github.io/Wormhole/fa/>
